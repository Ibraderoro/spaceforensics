Remaining Technical Debt

  • △ CSV path is case-specific. parseEvidenceCSV hardcodes galaxy15_evidence.csv. Server.js carries a TODO comment. Any new case requires a code change before the multi-case endpoint works.
  • ▪ No HTTP integration tests. The forensic-analysis API endpoints are tested via direct function-call unit tests (F25–F32, F33–F47), not via supertest HTTP request tests. The route logic (404 guards, error propagation) is covered only incidentally.
  • ▪ LLM path has no live test coverage. WATSONX_AI_APIKEY is absent in the test environment; all test runs exercise only the heuristic fallback. The LLM path is validated at the output level but no integration test covers it end-to-end.
  • ▪ CAUSAL_CERTAINTY_PHRASES regex is phrase-list based. The validator catches known exact phrases. Novel paraphrases of causal certainty not in the phrase list would pass A8/B3. This is an acceptable MVP limitation but warrants a note for future LLM model upgrades.
  • ▪ evidenceType returns null for GOES11_EPHEMERIS. The evidenceType() helper only classifies CASE and GOES11_* sources; GOES11_EPHEMERIS receives 'environmental_observation' (starts with GOES11_) — this is technically correct but is not explicitly tested as a separate classification. Observed empirically via F22 provenance test.

Remaining Scientific Limitations

  • △ Causal attribution cannot be established from this dataset. causal_attribution_established is permanently false for Galaxy 15. Key discriminating data — spacecraft command-subsystem telemetry, onboard fault logs, RF link monitoring, and direct in-situ particle measurements at the Galaxy 15 bus — are absent and cannot be recovered.
  • △ GOES-11 is a proxy measurement ~2° of longitude from Galaxy 15. EP8 and MAG data establish the local space-weather environment at GOES-11 orbit; direct flux at the Galaxy 15 bus is unavailable. The ±10-minute temporal window is a heuristic selection convention, not a calibrated causal threshold.
  • △ 5-minute EP8 averaging masks sub-minute impulsive flux events. A single-event upset may be caused by a particle flux increase lasting seconds; 5-minute averaged data cannot resolve this. The exact particle environment at the moment of the anomaly is unknowable from this dataset.
  • △ H1 and H2 are correctly mixed, not supported. The mixed assessment reflects a documented scientific limitation: EP8/MAG records establish environmental preconditions but provide no direct evidence of a mechanism (no ESD record, no single-particle track, no onboard SEU counter). This is not ambiguity in the system — it is the correct forensic statement.
  • △ H3 is supported, not strongly_supported. The anchor event (persistent command unresponsiveness) is consistent with an internal fault but does not establish the underlying mechanism (hardware, software, latchup, power-state). The distinction between supported and strongly_supported is preserved.
  • △ H5 (insufficient evidence for causal attribution) is the most strongly supported outcome. This is the correct conclusion. Its strong support reflects the absence of discriminating data across the entire dataset, not a failure of analysis.
